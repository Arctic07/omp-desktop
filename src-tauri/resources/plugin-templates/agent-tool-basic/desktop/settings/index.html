About this template

本页是模板自带的设置页示例。宿主会把插件在 omp.settings 里声明的键渲染成表单，排在它旁边：

  • note — 单行文本
  • mode — 枚举（safe / fast）
  • limit — 数字（1–10，步长 1）
  • verbose — 开关

这几个键都是模板示例：照抄形状，把键名、说明与默认值换成你自己插件的设置。

它们只是示例也有一层原因：值的读写都归引擎（锁文件 + 项目覆盖），v1 没有给插件代码读取自身设置的通道， 所以这个模板扩展模块并不读它们 —— 需要让代码读设置时，先确认引擎提供了对应 API，再接线。
